## CVE Overview

```
CVE ID:    CVE-2025-11494
CWE:       CWE-125 (Out-of-bounds Read) + CWE-119
Project:   GNU Binutils 2.45
File:      bfd/elfxx-x86.c
Function:  _bfd_x86_elf_late_size_sections()
Patch:     b6ac5a8a5b82f0ae6a4642c8d7149b325f4cc60a
Bugzilla:  33499

Root cause:
  In _bfd_x86_elf_late_size_sections(), the plt_eh_frame section
  processing reads from plt_eh_frame->contents with a size derived
  from plt_eh_frame->size, but does not validate that size is within
  the bounds of the contents allocation.
  When size exceeds the allocation, the read accesses memory beyond
  the heap boundary (CWE-125, out-of-bounds read).

This is structurally identical to the paper's running example
(CWE-122 heap-based buffer overflow at elfxx-x86.c:2699),
differing only in read vs write direction.

Trigger:
  Craft an ELF input where:
    plt_eh_frame->size > sizeof(plt_eh_frame->contents allocation)
  → _bfd_x86_elf_late_size_sections reads past allocation boundary
```

## Phase 2: LLM + Symbolic Execution

### Driver Template (based directly on paper Figure 3b)

```c
/*
 * KLEE driver for CVE-2025-11494
 * Based on Sailor paper Figure 3b with adaptation for CWE-125.
 *
 * Key difference from paper running example:
 *   Paper:   OOB write — klee_assume(sz > 16) triggers write overflow
 *   This:    OOB read  — klee_assume(sz > 16) triggers read overflow
 *   Driver structure is IDENTICAL. Only assertion direction differs.
 */

#include "bfd.h"
#include "elf-bfd.h"
#include "elfxx-x86.h"
#include <klee/klee.h>
#include <stdlib.h>
#include <string.h>

int main() {
    /* (1) Allocate top-level bfd and link_info — paper step (1) */
    bfd *out = calloc(1, sizeof(bfd));
    struct bfd_link_info *info = calloc(1, sizeof(struct bfd_link_info));
    klee_assume(out != NULL);
    klee_assume(info != NULL);

    /* (2) Allocate elf_x86_link_hash_table — paper step (1) */
    struct elf_x86_link_hash_table *htab =
        calloc(1, sizeof(struct elf_x86_link_hash_table));
    klee_assume(htab != NULL);

    /* (3) plt_eh_frame must not be NULL — paper step (2) guard bypass */
    htab->plt_eh_frame = calloc(1, sizeof(asection));
    klee_assume(htab->plt_eh_frame != NULL);

    /* (4) Symbolic buffer for contents — paper step (3) */
    unsigned char *dst = malloc(16);
    klee_make_symbolic(dst, 16, "dst_bytes");
    htab->plt_eh_frame->contents = dst;
    klee_assume(htab->plt_eh_frame->contents != NULL);  /* guard bypass */

    /* (5) Symbolic source buffer — paper step */
    unsigned char *src = malloc(512);
    klee_make_symbolic(src, 512, "src_bytes");
    htab->plt.eh_frame_plt = src;

    /* (6) Symbolic size — paper step (5) symbolic scalar */
    size_t sz;
    klee_make_symbolic(&sz, sizeof(sz), "copy_size");
    htab->plt_eh_frame->size = sz;

    /* (7) Violation condition — CWE-125 OOB read
     *     sz > 16: read past 16-byte dst allocation
     *     sz <= 512: keep within src to avoid spurious error */
    klee_assume(sz > 16);    /* violate bound → OOB read */
    klee_assume(sz <= 512);  /* keep src valid */

    /* (8) Wire htab into bfd tdata */
    elf_x86_tdata(out)->htab = htab;

    /* (9) Call entry function — paper step (6) */
    _bfd_x86_elf_late_size_sections(out, info);

    return 0;
}
```

### Assertion Template Application

```
Template (CWE-125): n <= min(len(dst), len(src))

Operand binding:
  n   = sz          (symbolic, klee_make_symbolic)
  dst = contents    (16 bytes allocated)
  src = eh_frame_plt (512 bytes allocated)

Violation:
  klee_assume(sz > 16)    → n > len(dst) → OOB read
  klee_assume(sz <= 512)  → n <= len(src) → no spurious src error

KLEE detects: READ of size N past 16-byte allocation
```
